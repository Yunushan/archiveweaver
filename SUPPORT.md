# Support

ArchiveWeaver is currently an alpha, community-maintained operations framework.
The repository does not provide a commercial support contract, guaranteed
response time, hosted service, or blanket certification for any cataloged
product.

Use public issues for reproducible, non-sensitive defects and feature requests.
Use the private process in `SECURITY.md` for vulnerabilities or suspected data,
credential, integrity, or supply-chain exposure. Never post customer data,
archive content, tokens, keys, inventories, or unredacted controller logs.

Every production deployment must name its own service owner, primary and
secondary on-call paths, escalation policy, SLA, RPO, and RTO. Those bindings
and their evidence belong in the environment-specific readiness manifest; they
cannot be inherited from this repository.
